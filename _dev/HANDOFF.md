## 3. How index.html is organized

**Look:** early-2006 "Web 2.0" (glossy masthead, rounded tabs, tag cloud, 80x15 badges, hit counter), themed on Seattle: Puget Sound teal `#2c7787`, ferry orange `#f07a1c`, overcast neutrals. Fonts are system stacks only (Trebuchet MS, Verdana, Lucida Console; Tahoma in the XP parts). Every color is a CSS token on `:root` with dark-mode overrides (`prefers-color-scheme` and `[data-theme]`).

**Main site** (hash routes, one page):
- Tabs: `#home`, `#projects`, `#resume`, `#blog`, `#contact`. A single project is `#p-<id>`.
- `PROJECTS` and `RACKS` arrays in the script hold all project data. There are three racks: Infrastructure (A01), Networking (A02), Security (A03). The Projects tab shows the racks with one detail panel and Previous/Next.
- Masthead: SVG skyline with the Space Needle and Rainier, plus a canvas rain effect.
- Sidebar: live Seattle time and Sea-Tac weather (National Weather Service station KSEA). The weather request is made once and shared as `SEA_WX`.
- Contact form posts to **Formspree form `mnppzkrr`** with JSON and shows inline status, with a mailto fallback.
- Ctrl+K or `/` opens a command palette (`CMDS` array), which includes "Replay intro" and "Toggle rain".

**Intro splash** (PR #3), a small Windows XP-style desktop:
- A script in `<head>` adds `html.intro` before first paint. It only does this when landing on the home page with no hash, on the first visit this session (`sessionStorage.introSeen`), and not when the visitor has reduced motion turned on.
- The animated pointer double-clicks the dunne.systems icon, the dialing GIF plays, and then the tray balloon and an **Open dunne.systems** button appear. The intro waits for a click; it never fades on its own.
- The real pointer takes over once the mouse moves (the `.live` class).
- Leaving the desktop: the Open button, the dialing window's X, any `[data-go="<route>"]` link, or Esc.
- JS modules, in file order: `Scene` (live wallpaper), `WM` (window manager: drag, minimize, maximize, close, taskbar buttons), `Apps` (resume reader, Projects Explorer, Notepad), `LMINFO` and `MapApp` (Map.exe), then `Intro`.
- Click delegation on `#xp` handles these attributes: `data-go`, `data-app`, `data-np` (opens a project in Notepad), and `data-copy`.
- **Live wallpaper (`Scene.apply(date, nwsDescription)`):** the Kerry Park view (Space Needle, downtown, Rainier, Elliott Bay). The sky comes from a real solar-elevation calculation for Seattle (night, twilight, golden hour, day). Weather comes from the KSEA description: clear, partly, mostly, overcast, drizzle, rain, storm with lightning, snow, or fog. It also draws the moon phase and lights the city at night. The tray shows the Sea-Tac temperature.
- Desktop icons: dunne.systems, Map, Resume.pdf, Projects.

**Map.exe** (`MapApp`):
- A 1600x1000 "world" made of the terrain JPG plus an SVG overlay, inside `.map-stage`, which is panned and zoomed with a CSS transform.
- Drag to pan, wheel or pinch to zoom, or use the zoom bar and "Whole map."
- Clicking a landmark flies to it; the click reads its `translate(x y)` from the transform. Then it opens a window filled from `LMINFO[key]`.
- The status bar shows the hovered place and fake coordinates. The terrain is tinted by `Scene.current.phase`.
- Landmark keys: `needle` (contact), `akamai`, `homelab` (projects), `school` (ZTP volunteer), `grc` (Green River College), `pisces` (SOC analyst), `ccdc` (PRCCDC), `rainier` (about), `hub` (Cloud Hub inset with certifications).

**Design rules followed so far** (keep them):
- **Original art only.** No copied Magdalena Bay assets, no Windows logo; the XP Start button uses the Rainier icon.
- **Safety and courtesy.** No personal data in URLs, and no trackers. The visit counter lives in localStorage only.
- **Phone-friendly.** XP windows go full-screen at 600px wide or less.

## 5. NEXT TASK: give Map.exe real geography

**Problem (Andrew's feedback):** the cloud session couldn't download coastline data, so `terrain.py` draws the coast as freehand polygons. The result reads wrong. The narrow channel with an island looks like Lake Washington and Mercer Island, which makes the west landmass (where the "PRCCDC Arena" sits) look like Seattle.

**Goal:** rebuild the terrain from real data so Puget Sound reads correctly at a glance:
- Puget Sound as the wide main basin, with Elliott Bay at downtown.
- Bainbridge Island west of Seattle, and Vashon Island to the southwest.
- The Kitsap Peninsula on the west side.
- Lake Washington with Mercer Island inside it, plus Lake Union and Lake Sammamish.
- Commencement Bay at Tacoma, if it is in frame.

**Suggested approach:**
1. **Get data.** Any one of these works:
   - `pip install basemap basemap-data-hires` (GSHHG full-resolution shoreline: level 1 land, 2 lakes, 3 islands in lakes, which includes Mercer Island).
   - Natural Earth 10m `ne_10m_land` + `ne_10m_lakes` + `ne_10m_minor_islands` GeoJSON from `nvkelso/natural-earth-vector`. Probably too coarse for Mercer Island.
   - OpenStreetMap water polygons or an Overpass query for the bounding box.
2. **Pick the bounding box and projection.** Suggested box: **lat 47.25 to 47.78, lon -122.97 to -121.72**. That is close to the 1.6:1 aspect ratio when drawn in Web Mercator. Use **one projection function** for both the terrain and the landmark positions.
3. **Rasterize the land mask** at 1600x1000 (land filled, lakes cut out, islands in lakes filled back in). Feed it to `terrain.py` in place of the hand-drawn `east`, `kitsap` and `Vashon` polygons and the hand-drawn lake polygons. Keep the existing look: fbm noise, hillshading lit from the northwest, saturated CD-ROM greens, shallow-water foam, and film grain.
4. **Rainier is about 60 miles southeast**, outside this box (46.853, -121.760). Show it as a distant mountain in the bottom-right corner, labeled something like "Mt. Rainier (60 mi SE)", instead of faking its position. Or extend the box south if the landmarks still fit.
5. **Re-place the landmarks** in `landmarks.py` (`LM` list) using real coordinates, projected the same way:

   | Key | Place | Lat, lon |
   |---|---|---|
   | needle | Space Needle | 47.6205, -122.3493 |
   | homelab | Renton (south tip of Lake Washington) | 47.4829, -122.2171 |
   | akamai | Data center in the Kent or Tukwila valley ("Greater Seattle") | about 47.40, -122.25 |
   | grc | Green River College, Auburn (Lea Hill campus) | 47.3127, -122.1804 |
   | school | Volunteer high school labs (no exact spot; Federal Way or Kent area) | about 47.32, -122.31 |
   | pisces | Washington local government SOC (no fixed spot; ask Andrew; Bellevue is a placeholder) | about 47.61, -122.20 |
   | ccdc | PRCCDC (ask Andrew where it should go; Kitsap side is a placeholder) | about 47.57, -122.63 |
   | rainier | Corner decoration, see step 4 | n/a |

   Then update the `main` and `branch` fiber paths to pass through the new points. A nice touch: route the fiber across Lake Washington on the I-90 bridge line, and route the Kitsap link as an undersea cable. Also update the `ferryroute` path to match a real Seattle–Bainbridge ferry crossing.
6. **Regenerate and inject:**
   ```bash
   python3 _dev/map/terrain.py          # writes assets/images/map-terrain.jpg
   python3 _dev/map/landmarks.py        # writes _dev/map/overlay.svg
   python3 _dev/map/apply_overlay.py    # injects it into index.html
   ```
7. **Update the coordinate readout** in `MapApp.init` (the `coord.textContent` line). It currently uses a fake linear mapping. Make it the inverse of the projection used in steps 2 and 5.
8. **Check it.** Screenshot the whole map and confirm a Seattle local would recognize it: Seattle on the east shore, Mercer Island inside Lake Washington, Renton at the south end. Then commit to `intro-splash` and push. PR #3 updates automatically.

Keep the terrain JPG under about 300 KB (it loads only when Map is opened).
